# Requirements Document

## Requirements

### Requirement 1: Sign in

**User Story:** As a user, I want to sign in, so that I can reach my account.

#### Acceptance Criteria

1. WHEN the user submits valid credentials, THE Login_Form SHALL open the dashboard
2. WHEN the credentials are invalid, THE Login_Form SHALL show an error

### Requirement 2: Password reset

**User Story:** As a user, I want to reset my password, so that I can recover my account.

#### Acceptance Criteria

1. WHEN the user asks for a reset, THE Login_Form SHALL link to the reset page
