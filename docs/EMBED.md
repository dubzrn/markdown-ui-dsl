# Embedding wireframes (T-094)

`@mdui/embed` turns a `mdui` code fence into a self-contained SVG (or semantic HTML) and ships adapters for
markdown-it, remark and rehype. It depends only on `@mdui/core` and `@mdui/render`; no markdown library is imported
(the adapters are structural), so `@mdui/core` stays dependency-free.

## The fence

````markdown
```mdui style=sketch state=loading theme=dark width=480 output=svg
::: CARD :::
# Welcome Back
[ text: Email Address ]
[ Login ](#login)
--- END ---
```
````

| Option | Values | Default |
|---|---|---|
| `style` | `clean`, `wireframe`, `sketch` | `clean` |
| `theme` | `auto`, `light`, `dark` | `auto` (follows `prefers-color-scheme` inside the SVG) |
| `state` | a STATE name | `default`, then the first |
| `width` | 240-1600 (px) | 640 (SVG only) |
| `output` | `svg`, `html` | `svg` |

Unknown or invalid options are ignored and reported (`parseFenceInfo(...).warnings`, and on the CLI).

## SVG output

Self-contained: real `<text>` (not outlines), no external fonts, images, scripts or `href`s, one small `<style>` block,
`role="img"` with `<title>` and a `<desc>` that lists the headings, controls and text drawn. Deterministic: the sketch
style's wobble is seeded from each shape's geometry. The login example is about 2.3 kB (budget: 50 kB).

Limits you should know about: layout uses **estimated text metrics** (a picture of the wireframe, not a browser), rows and
grids use equal-width columns, items in a row are not stretched to equal heights, and there is no per-element
interactivity. For exact layout use `@mdui/render` (`output=html`).

## Adapters

```ts
import MarkdownIt from "markdown-it";
import { markdownItMdui, remarkMdui, rehypeMdui } from "@mdui/embed";

new MarkdownIt().use(markdownItMdui).render(md);

unified().use(remarkParse).use(remarkMdui)
  .use(remarkRehype, { allowDangerousHtml: true })
  .use(rehypeStringify, { allowDangerousHtml: true });
// rehypeMdui: for pipelines that reach hast with <pre><code class="language-mdui">
```

All three render the fence body only; the SVG/HTML they emit is escaped (hostile text in a spec cannot add elements).
Include resolution (`[[ USE: path ]]`) needs the `readFile` option; without it includes draw as placeholders.

## GitHub and READMEs

GitHub renders Mermaid natively but not custom fences, so the GitHub-friendly form is a generated image:

```
mdui embed README.md --write --out-dir docs/img        # replaces each mdui fence with ![alt](docs/img/<hash>.svg)
mdui embed README.md --write --keep-source             # also keeps the source in a collapsed <details>
mdui svg examples/login-form.ui.md --style sketch --out docs/img/login.svg
```

File names are a hash of the fence info and body, so they change only when the wireframe does. The SVGs in this page are
generated by `node scripts/gen-embed-docs.mjs` and checked for staleness in CI.

## Obsidian

`registerObsidianMdui(plugin)` registers an `mdui` code-block processor that inserts the SVG parsed with `DOMParser`.
