- Status: **Accepted** — maintainer instruction "Accepted; proceed", 2026-10-01. The instruction was given while this RFC was still a pending task, so the text below (including §7 simplifications) has **not** yet had a line-by-line maintainer read; the simplifications are marked and reversible.

- Features / REQs: LNG-02…LNG-08, LNG-10, LNG-11, LNG-13 · REQ-LNG-02, 02b, 03…08, 10, 11, 13
- Depends on: ADR-005 (v1 decisions D1–D15), SP-4 baseline (`docs/spikes/SP-4-token-cost.md`)
- Normative grammar delta: `packages/spec/grammar/v2.ebnf`. This RFC replaces the drafts in `docs/SPEC.md` §2.2 where they differ (§7).

## 1. Summary

DSL 2.0 adds, **only for documents declaring `dsl: 2.0`**: typed closers, attribute lists, new primitives, regions/states, path-only data binding, partials, flow files, an action registry, and environment directives. Documents without `dsl:` (or `dsl: 1.x`) parse exactly as in 1.0.3.

## 2. Motivation

Four of seven shipped examples were unbalanced (B-01) because a bare `--- END ---` gives no mismatch signal (typed closers fix it); there are no states, data, or flows to wireframe real products (G-gaps in COMPETITIVE_RESEARCH §5); and agents need stable ids/attributes to anchor sync (NOV-01) and accessibility (QLT-03).

## 3. Syntax and semantics

Every construct, one example, one sentence. Sub-parts follow the T-012 split.

### 3a. Closers, attributes, field attributes (LNG-02, LNG-03)

```markdown
::: CARD :::{: #login-card .elevated }
[ text: Email ]{: #email type=email required label="Email" }
[ Delete account ](#delete){: destructive }
--- END CARD ---
```

- **Typed closer** `--- END <KIND> ---` closes the innermost block and must match its kind (`CARD`, `COLUMN`, `ROW`, `MODAL`, `HEADER`, `FOOTER`, `BUBBLE`, `REGION`, `STATE`, `GRID`, …); otherwise `E1004` naming the expected kind. Generic `--- END ---` still closes the innermost block.
- **Attribute list** `{: … }` directly after a component or block opener: `#id`, `.class`, `key=value`, `key="quoted value"`, bare `flag`. It is recognised only when `{:` is followed by a space, `#`, `.` or a word character, so dropdown options (`{A, B}`) and bindings (`{{ x }}`) never collide.
- **Reserved keys:** `label hint error alt role live required readonly disabled type min max step pattern maxlength autocomplete scroll primary destructive terminal lang dir`. Unknown keys are kept and warned (`W1301`); duplicate `#id` in a document is `E2001`; invalid value for a reserved key is `E1301`.

### 3b. New primitives (LNG-04)

Widget form `[ KIND: args ]{: attrs }` (KIND upper-case, unlike `text:`/`IMG:` of 1.x which keep their spelling), container form `::: KIND args :::`.

| Group | Syntax |
|---|---|
| Form | `[ SLIDER: 0..100 step=5 value=40 ]` `[ DATE: 2026-03-15 ]` `[ FILE: Upload CV (pdf, docx) ]` `[ PROGRESS: 75% ]` |
| Data | `[ CHART: line "Revenue" data=revenue ]` `[ STAT: "Active users" 1,204 (+4%) ]` `[ SKELETON: rows=5 ]` `[ AVATAR: Jane Doe ]` `[ ICON: bell ]` `[ CRUMBS: Home > Settings > *Profile* ]` `[ PAGER: 3/10 ]` `[ STEPPER: Account > *Profile* > Plan ]` |
| Menu | `[ MENUBAR: File \| Edit \| View ]` |
| Containers | `::: GRID cols=3 :::` `::: ACCORDION :::` (`::: PANEL "Title" open :::`) `::: DRAWER side=right :::` `::: TOAST kind=success :::` `::: TOOLTIP for=#id :::` `::: CALLOUT info :::` `::: EMPTY :::` `::: TREE :::` (nested list items) `::: GROUP "Title" :::` |
| Divider | `*** Section title ***` (bare `***` unchanged) |

Unknown `KIND` in 2.0 ⇒ `E1302` with the nearest known kind as fix hint. Each primitive has a typed node (T-021).

### 3c. Regions, states, data, includes (LNG-05, LNG-06, LNG-07)

```markdown
::: REGION users :::
::: STATE default :::
| Name | Role |
| --- | --- |
| {{ user.name }} | {{ user.role }} |
--- END STATE ---
::: STATE loading :::
[ SKELETON: rows=5 ]
--- END STATE ---
--- END REGION ---
[[ USE: ./partials/nav.ui.md ]]{: items="Home,Pricing" }
```

- `REGION` groups mutually exclusive `STATE`s (`default`, `loading`, `empty`, `error`, `disabled`, `success`, or `[a-z][a-z0-9-]*`); a region with states lacks `default` ⇒ `W3201`.
- `{{ a.b.c }}` is a **path only**: identifiers and dots (and `[n]` indexes). No calls, operators or arithmetic — they are not parsed and yield `E2102`. A path unknown to `data:` ⇒ `E2101`. `::: EACH item in items :::` repeats a block; `::: IF path :::` / `::: IF !path :::` conditionally includes one.
- `[[ USE: path ]]{: props }` inlines a partial (`type: partial`); props appear as `{{ props.x }}`. The path is relative and sandboxed to the project root: a `..` escape is `E2301` and the file is never read; max depth 8; cycles `E2302`. File access is through an injected reader (core stays I/O-free).

### 3d. Flows, actions, environment directives, constraints (LNG-08, LNG-11, LNG-13, NOV-04 syntax)

```markdown
---
dsl: 2.0
type: flow
start: login
---
## Screens
| id | file | terminal |
| --- | --- | --- |
| login | ./login.ui.md | |
| dashboard | ./dashboard.ui.md | |
## Transitions
- login #login -> dashboard [when: credentials valid]
```

- **Transition:** `- <screen> #<action> -> <screen> [when: text]`. `#action` must exist on the source screen (`E2401`); an unknown screen id is `E2402`.
- **Action registry** in frontmatter `actions:`; a button `(#name)` resolves to it; unknown target ⇒ `E2501`; `destructive: true` is carried to lint (T-026).
- **Environment directives** extend `> @…`: `@dark @light @print @reduced-motion @contrast-more @touch @hover`, combinable with a breakpoint (`> @md @dark surface: inverted`). Under 1.x these are `W1201` plain hints (fixture `directive-unknown-bp-dark-v1`).
- **Constraints:** frontmatter `constraints:` or `> constraint: rule=value`; waiver `> waive: rule reason="…"` (semantics: NOV-04).

## 5. Diagnostics added

`E1004` typed-closer mismatch · `E1301` bad attribute value · `E1302` unknown primitive · `W1301` unknown attribute key · `E2001` duplicate id · `E2101` unknown data path · `E2102` unsupported expression in binding · `W3201` region without `default` · `E2301` include escapes root · `E2302` include cycle · `E2401` flow action not found · `E2402` flow screen not found · `E2501` unknown action. (Registered in `@vrillabs/mdui-core` as each task lands, T-020…T-026.)

## 6. Compatibility

- **v1 documents** (no `dsl:` or `dsl: 1.x`): unchanged. The compatibility gate (T-024) asserts equal ASTs on all v1 fixtures with and without `dsl: 2.0` where semantics are shared.
- **Where 2.0 changes meaning of v1 text** (only when `dsl: 2.0`): a `--- END X ---` line (plain text in 1.x by D3), `{: … }` after a component, `{{ path }}` in text, `[ KIND: … ]` with upper-case KIND, `*** Title ***`, `> @dark` etc. `mdui migrate` (T-0xx) reports each occurrence in a 1.x file that would change meaning when bumped.
- Escapes (D7) apply unchanged; `{`, `}` are already escapable, so `\{\{ x \}\}` is a literal.

## 7. Readability review and simplifications (SPEC §2.2 amendments)

Constructs needing more than one sentence of explanation were flagged:

| Construct | Finding | Resolution in this RFC |
|---|---|---|
| Quoted attribute keys (`"quoted key"="v"`) | Rare; needs its own escaping story. | **Dropped**: attribute keys are bare identifiers. *(SPEC §2.2 amended.)* |
| Transition wildcard `*` action | Allowed any action; weakens `E2401`. | **Dropped**; list one transition per action. *(SPEC §2.2 amended.)* |
| `EACH` / `IF !` | Two conditional forms plus a loop. | Kept; **no `ELSE`** (use `IF !`). |
| `[ CHART: line "t" data=x ]` | Mixed positional/quoted/keyed args. | Kept; arguments are positional-then-keyed, quoted only when containing spaces. |

## 8. Token budget (SP-4)

2.0 additions must stay terse relative to A2UI JSON (baseline −85.8% for 1.x). Binding `{{ x }}` ≤ 4 tokens vs `{"path":"/x"}` ≈ 6. SP-4 is re-run after T-020…T-023 with capability-matched scenarios; a construct whose measured cost erodes the saving below 60% is a candidate for simplification before GA.

## 9. Alternatives considered

JSON-Pointer bindings (A2UI): rejected, token-heavy and unfamiliar to designers. Expression language in bindings (Markdoc functions, Mustache helpers): rejected, a code-execution surface and a long-term parser burden (path-only keeps E2102 simple). Separate flow DSL (Wiremark named frames, Salt): kept flows as a Markdown file type for one toolchain.

## 10. Security

Includes are root-sandboxed with an injected reader; bindings never evaluate; action registry never executes; nothing in a `.ui.md` is an instruction to the agent (AGENTS.md "Never"). Binding values from `data:` are treated as text, never as DSL.

## 11. Unresolved questions

1. Whether `PROGRESS`/`STAT` remain widgets or become attributes of text (decide with T-021 fixtures).
2. Whether `type: flow` screens may inline small screens (out of scope for 2.0 GA).
3. Names `mdui`/`@vrillabs/mdui-*` (SPEC §0, assumption A2).
