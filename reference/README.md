# `reference/` — vendored reference implementations

**32 upstream repositories checked in as git submodules** so any contributor or coding agent can read, search and *lift* proven code instead of re-inventing it. This folder is **read-only study material**: it is not built, linted, tested or published, and nothing in `packages/` may import from it.

> Why it exists: every wheel this project needs — parsers, schema validators, streaming, SVG renderers, token linters, ARIA-tree computation, grammar emitters, eval harnesses, conformance suites — already exists somewhere in this folder. The job is to **find it, take it (legally), and make it better**, never to rewrite it blind.

## Quick start

```bash
# New clone: submodules are NOT fetched by default (keeps clones small).
git clone https://github.com/dubzrn/markdown-ui-dsl.git && cd markdown-ui-dsl
scripts/reference.sh init all            # or a group: dsl | protocols | tokens | sdd | verification
scripts/reference.sh sparse              # apply sparse patterns (Playwright)
scripts/reference.sh status              # pin, date and licence of every repo
scripts/reference.sh find 'streaming' protocols   # search all reference code (ripgrep/grep)
scripts/reference.sh lift reference/dsl/markdoc/src/formatter.ts packages/tools/src/fmt/markdoc-formatter.ts
```

`init` uses shallow (`--depth 1`) checkouts. Full size when everything is initialised is roughly 1.3 GB on disk (the large ones are listed in the table); `git clone` of this repo itself stays small because submodules store only a pinned commit.

## The "beat the wheel" protocol (mandatory for any lift)

1. **Search first.** Before writing a non-trivial module, run `scripts/reference.sh find <concept>` and check the manifest table below ("Lift / study first").
2. **Check the licence.** `scripts/reference.sh lift` detects it and **refuses** unknown licences; copyleft (MPL/GPL/AGPL/LGPL) needs maintainer sign-off (`--allow-copyleft`) — see SPEC §7 "Ask first". Apache-2.0 requires preserving notices and marking changes; MIT/BSD require keeping the copyright notice.
3. **Lift by copying, never edit in place.** `scripts/reference.sh lift <src> <dest>` copies the file and appends an entry (date, destination, upstream repo, source path, pinned commit, licence) to [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Keep upstream licence headers in lifted files.
4. **Then improve it** — a lift is only done when the PR shows at least one concrete improvement over upstream and says which:
   - *Correctness*: add the missing edge-case tests / conformance fixtures; fix what the tests reveal.
   - *Fit*: strict types, diagnostics-not-exceptions (SPEC §5), spans on every node, zero runtime dependencies in `@mdui/core`/`@mdui/spec`.
   - *Safety*: path sandboxing, URL-scheme allow-list, no `eval` (AGT-04).
   - *Accessibility*: semantic output, ARIA roles, WCAG 2.2 exceptions modelled (QLT-03).
   - *Performance*: measured against the T-044 budgets, not guessed.
   - *Determinism*: stable ordering and idempotence (property-tested).
5. **Prefer concepts over code when licences or shapes differ.** Read the reference, then implement against our grammar/AST; cite the reference path in the PR.
6. **Contribute back** where the upstream license and maintainers welcome it; at minimum file upstream issues for bugs found.
7. **Never** edit anything under `reference/` (the pins are the audit trail). Bump a pin only with `scripts/reference.sh update <path>` in a dedicated PR (PLAN §13 cadence).

## Licence handling

| Licence class | Rule |
|---|---|
| MIT / BSD / ISC | Lift allowed; keep copyright + licence text; logged automatically. |
| Apache-2.0 | Lift allowed; keep `LICENSE`/`NOTICE` obligations and mark modified files; logged automatically. |
| MPL-2.0 | **File-level copyleft** — modified/derived files stay MPL. Needs sign-off; prefer reading the design and re-implementing. |
| GPL / AGPL / LGPL | Not allowed without explicit maintainer decision. |
| W3C Software and Document License / W3C 3-clause BSD | DTCG: spec text and test suites may be reused with attribution; read the exact terms before lifting. |
| Declared only (no `LICENSE` file) | Wiremark and ASCIIwire declare MIT in `package.json`/README but ship no licence text → treated as **unknown**: study-only until the maintainer confirms (e.g. by asking upstream to add a LICENSE). |
| Unknown / none | Not allowed (`lift` refuses) until the licence is read and signed off — e.g. Kiro (docs repo, no licence file). |

Licences below are **detected heuristically** from each repo's `LICENSE` file — re-read the real file before any lift. Sub-directories can carry different licences (e.g. `LICENSE-3RD-PARTY.txt`, vendored code).

## Maintenance

- **Pins:** each submodule is pinned to a specific commit (the gitlink in the index). `.gitmodules` marks them `shallow = true`.
- **Refresh cadence:** with each verification pass (PLAN §13): `scripts/reference.sh update <path>`, re-run `python3 scripts/reference-manifest.py`, review notable upstream changes, commit.
- **Adding a repo:** add its entry to `manifest.json` (role, lift targets, tasks), `git submodule add --depth 1 <url> reference/<group>/<name>`, set `shallow = true` in `.gitmodules`, regenerate the manifest. Large repos: use sparse checkout via `scripts/reference.sh sparse`.
- **Excluded from tooling:** `reference/**` is excluded from lint, format, tests, coverage, traceability and CI path filters (T-006) and marked `linguist-vendored`.
